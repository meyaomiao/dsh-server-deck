# 核心用户链路与发版复验

每批在同一冻结提交上执行以下链路，并把命令、测试进程版本、结果与截图写入发版 Issue。测试台账、SSH key 和配置使用隔离夹具；不覆盖日常桌面的活跃会话。

1. **冷启动与装载**：从干净 `lib/` 重建，在全新的 DSH `0.2.1-rc.5` 进程加载发布包，首页、客户端 bundle 与已认证 API 均为 200，日志无 inject / 未捕获异常，停止进程退出 0。
2. **主机台账**：新增、编辑、连接测试、删除；密码和私钥口令不出现在 API；显式清除凭据后持久化生效；仅改名称/标签保留连接，修改连接定义重建对应连接。
3. **导入预览与确认**：首次点击只读扫描，展示全部检测结果及原因；取消不写；勾选一台只新增该台及必需跳板；确认期间禁止重复提交，完成后展示新增/更新/跳过数量；配置变化要求重新检测。
4. **跳板关联**：普通别名、限定用户名/端口、多级 ProxyJump、既有目标补关联；缺失、自指、环与冲突不静默直连；编辑/删除任意跳板祖先后下一次连接采用新配置。
5. **终端**：从卡片打开真实 SSH 提示符，输入、输出、窗口 resize、返回与重新进入正常；浏览器与 DSH Connection 桌面 carrier 均使用宿主 transport。表头只有一层，在 900/600/540/320/240px 容器不越界，长标题省略、窄容器 endpoint 隐藏。
6. **状态与趋势**：最新在线状态、CPU/内存/磁盘、网速/月流量可读；趋势切换 1h/24h/7d/30d 与自定义，采集周期切换与停用正常，离线/无数据有明确显示。
7. **对话工具**：列出台账且不含秘密；非交互命令返回退出码与输出；Windows 包装行为继续由回归覆盖；工具不向已打开的 xterm 灌键。
8. **请求准入**：匿名 REST/PTY 401，错误 Origin/Host 403；缺少/失效宿主授权 API 503；拒绝请求不读台账、不创建 SSH shell；合法已认证请求可用，不在 query 放长期凭据。
9. **资源与样式生命周期**：无关插件样式处理不影响已有归属；删除标签后可重建；PTY 断开/卸载、晚到 shell、pending SSH、异步初始化期间卸载均能清理，退出后不复活连接或采集器。

## 可重复命令

```bash
pnpm install --frozen-lockfile
pnpm build
pnpm typecheck
pnpm test
pnpm exec playwright install chromium
pnpm test:ui
npm pack --dry-run
```

构建脚本会在自身工作目录删除并重建 `lib/`，运行前核对目录。开发底座提交/运行前另执行 `pnpm gate`，并使用相同 gate 的 `checkPackage` 扫描独立仓的 host/client 入口。

自动化浏览器测试使用真实 React/xterm 与合成 REST/WS 夹具；它们与新 DSH 进程的端到端验证分别留证。Windows 真桌面、真实生产服务器等未实际运行的场景如实列出验证边界。

## 发布后

从 npm 渠道重新安装确切版本，重复第 1、5、8 项及导入确认；核对 npm 版本、GitHub tag 与包内 version 一致。只把经实际验证的结果写为通过。
